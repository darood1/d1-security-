D1 SECURITY WEBSITE

Upload the CONTENTS of this folder to the root of your hosting or GitHub Pages repository.

Pages: / (index.html), /services (services/index.html), /contact (contact/index.html).
Navigation links intentionally omit .html. The .nojekyll file is included.

Images: original editable SVG illustrations in /images. Replace with your own JPG/PNG/WebP images and update the corresponding image paths in HTML/CSS.

IMPORTANT: The enquiry form uses mailto: to open the visitor's email application. This requires a configured email app and is NOT server-side delivery. For automatic submission, connect a form service or server-side handler before launch.

Google Fonts require an internet connection.

BRANDING: images/d1-security-logo.png is the D1 Security company logo (transparent PNG). Navy and teal colours are applied across all three pages.
